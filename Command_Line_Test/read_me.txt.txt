Hey there!

I'm excited you're checking out the Command Line test project. Inside this repository, you'll find all the files needed to run a nifty shell script. These files play a crucial role in making the script run smoothly:

Colors.txt: It's got the color codes that make your terminal look snazzy.
Questions.txt and Answers.txt: They're like the Q&A for a cool Linux module.
user_name and user_passwd: These are like your usernames and passwords, but don't sweat it if they vanish. The script can recreate them as needed. They help the script verify users.
main.sh: The big boss shell file that you gotta run.

What This Project Does:
Signup: Yep, just like signing up for any website.
Signin: Once you're in, you can choose to take a test or just bounce. Definitely give the test a try!
Exit: Well, that's pretty self-explanatory, right?

P.S.: You won't see passwords in screenshots because they're hidden. To see passwords in the terminal, swap `read -sp` with `read -p` command.
